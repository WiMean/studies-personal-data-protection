# Защита персональных данных клиентов

**Задача.** Защитить персональные данные клиентов страховой компании так, чтобы по ним нельзя было восстановить исходную информацию, но качество модели машинного обучения не ухудшилось.

**Что сделано.** Обоснование обратимости преобразования, умножение признаков на случайную обратимую матрицу, доказательство сохранения качества модели, проверка на данных.

**Стек.** Python, pandas, NumPy, scikit-learn

**Результат.** качество модели не изменилось (R² ≈ 0,43)
